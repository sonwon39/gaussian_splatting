name: 이슈·피드백은 즉시 자동 저장
description: 사용자가 지시하지 않아도 이슈·피드백·프로젝트 맥락이 생기면 발생 시점에 바로 메모리에 기록해야 함
type: feedback
---

이슈·피드백·프로젝트 맥락이 생긴 **그 순간** 사용자의 명시 지시 없이도 자동으로 메모리에 저장할 것.

**Why:** 2026-04-20 작업 중 HEREDOC 실패, `autoMemoryDirectory` 제약 같은 이슈들을 발생 시점에 저장하지 않고 사용자가 "기록해줘"라고 따로 지시한 뒤에 저장함. 사용자가 매번 요청하지 않아도 되게 해달라고 명시함.

**How to apply:**
- 새로운 제약/실패/우회법을 발견한 순간 → feedback 메모리 즉시 작성
- 사용자가 선호/접근방식을 교정하거나 비자명한 선택을 승인한 순간 → feedback 메모리
- 레포의 목적·마감·의사결정 맥락이 드러난 순간 → project 메모리
- 저장 후 그 턴에 "메모리에 기록함"을 한 줄로만 알리고 넘어가기 (별도 확인 요구 금지).
