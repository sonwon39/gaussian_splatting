이 작업 공간의 목적은 **Gaussian Splatting (3DGS) 기술을 공부하고 실습**하는 것이다. GitHub 레포: https://github.com/sonwon39/gaussian_splatting.git

**Why:** 사용자가 학습/실습 목적으로 새로 만든 레포. 프로덕션 코드가 아니라 교육적 맥락이므로 설명·개념 해설·단계별 이해를 중시해야 한다.

**How to apply:** 코드를 작성하거나 변경할 때 왜 그렇게 하는지 개념(렌더링 파이프라인, 공분산 행렬, 스플랫 투영, 뷰 의존 색상 SH 등)을 함께 짚어 주기. 복잡한 최적화를 갑자기 도입하기보다, 기본 구현부터 단계적으로 쌓아 올리는 것을 선호. 외부 레포(inria-graphdeco/gaussian-splatting 등) 참조 시 출처 알려 주기.
